# Hide and Seek — Phase 2

夕暮れの公園で、赤鬼から隠れて仲間をたすけるゲーム。Android縦画面を優先したWebゲームです。

## 起動と公開

公開済みのURLを開けば遊べます。PCで試す場合は、このフォルダーで以下を実行し、`http://localhost:8000` を開いてください。

```sh
python -m http.server 8000
```

HTMLのダブルクリック（file://）ではモジュール・PWAが動かないため、HTTPで開いてください。

GitHub Pagesで公開するには、ZIPを展開し、中身の `index.html`、JS、CSS、manifest、`sw.js`、`icons`をリポジトリ直下に配置します。リポジトリの **Settings → Pages** でブランチから公開する設定を選び、**main / (root)** を指定して保存してください。すべて相対パスなので、リポジトリ名付きのURLに対応しています。

Android Chromeで公開URLを開き、メニューの「ホーム画面に追加」または「アプリをインストール」から追加できます。初回オンラインでキャッシュした後はオフライン起動にも対応しています。更新時は `sw.js` の `CACHE` 名を変更してください。Phase 2はPhase 1と異なるキャッシュ名です。既に開いている旧版は閉じ、公開URLを開き直してください。

## 操作

1. **1分・3分・5分**を選び、スタート。
2. **青い帽子と「操作中」の表示があるキャラ**を操作します。光る場所をタップすると自動で歩きます。下の「移動する場所」からも選べます。
3. 仲間が捕まったら、公園右側の**牢屋の前にある鍵マーク**へ移動すると、捕まっている仲間を全員解放できます。
4. 操作キャラが捕まったら、生存者へ**自動で交代**します。青い帽子も次のキャラへ移るので、同じように場所をタップしてください。
5. 救出後も、今操作しているキャラをそのまま操作します。元のキャラはCOMとして逃げます。

鬼は牢屋の前にも来ます。助けに行くタイミングを、鬼の向きと位置から決めましょう。解放された仲間は別々の隠れ場所へ逃げ出します。

通常は移動途中の行き先変更ができません。ただし、**「見つかりそう」と短いスローが出ている間は、移動中でも1回だけ行き先を選び直せます**。発見されてからの行き先変更はできません。

全員が捕まると敗北。時間切れまで1人でも残ればクリアです。スロー中も残り時間は通常どおり進みます。

- **♪ ON/OFF**：音の切替。音はスタート操作後に有効になります。
- **一時停止**：休憩。アプリやタブを離れた場合も自動停止します。
- **もういちど**：新しい試合。時間を選び直すこともできます。

## Phase 2の変更

- 牢屋と、到着すると全員解放する救出ポイントを追加。
- 捕獲後に生存者へ自動交代。操作中のCOMはAIの自動移動を停止。
- COMも、鬼が牢屋から離れたときに救出を判断。
- 救出成功の光・短い通知・SEを追加。
- 解放直後の仲間に2.2秒のゲーム内時間の保護を付け、出口で即座に再捕獲される連鎖を緩和。
- 救出には6秒のクールダウン。到着時にのみ発動し、立ちっぱなしで繰り返すことはありません。
- 鬼の視界・向き・遮蔽物・発見の進み具合に応じた1.35秒の危機スローを追加。通常0.6倍、発見直前0.42倍。
- スローは8秒のクールダウンに加え、危険度が一度下がらないと再発動しない仕組み。
- 操作交代後も、危険判定・心音・スローが操作中のキャラに追従。

## 今後のモード追加に使える構造

`engine.js` の `Game` は、表示・音・DOMから独立しています。3つ目の引数でルールオブジェクトを渡せます。

| 仕組み | 変更する箇所 |
|---|---|
| 救出の有無・クールダウン・解放後保護 | `rescueRules` の設定 |
| 捕獲後の配置先 | `capturedPosition(character)` |
| 救出するキャラの選び方 | `rescueTargets(game)` |
| 全滅・時間切れ等の勝敗条件 | `outcome(game)` |
| 捕獲・救出・操作交代 | `capture` / `rescue` / `switchControl` |
| 演出や通知 | `app.js` がイベントを受け取って描画・発音 |

通常かくれんぼは救出無効化、氷鬼は捕獲位置をその場に保持して接触救出、缶蹴りは救出トリガーを缶への到達に変更する、といった拡張ができます。接触救出・缶の描画等の追加実装は次Phaseで必要です。全モードが既に実装済みという意味ではありません。

スローでは全キャラ・鬼・視界の蓄積・AIが共通のゲーム内時間を使用します。制限時間とクールダウンには実時間を使用し、公平性と短いテンポを保っています。

## 検証

`VALIDATION.md` に結果と未確認項目を記載しています。

```sh
npm test
```

ロジックテストに外部パッケージは不要です。ブラウザテストを再実行する場合は `npm install --no-save playwright`、`npx playwright install chromium` を実行し、`node tests/browser.test.mjs` を使ってください。

アカウント、広告、アクセス解析、外部へのユーザー情報送信はありません。ゲームの実行に外部ライブラリ・外部サーバーは不要です。
