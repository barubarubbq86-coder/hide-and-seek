# Hide and Seek — Phase 1

夕暮れの公園で、赤鬼から逃げる見下ろし型かくれんぼ。Android縦画面向け。外部サーバー、アカウント、外部ライブラリは不要です。

## 起動

公開後はブラウザでGitHub PagesのURLを開くだけで遊べます。

PCで試す場合は、このフォルダーで以下を実行し、`http://localhost:8000` を開きます。

```sh
python -m http.server 8000
```

HTMLファイルのダブルクリック（file://）ではJavaScriptモジュールやPWAが動かないため、HTTPで開いてください。

## GitHub Pagesで公開

1. ZIPを展開します。
2. GitHubリポジトリの直下に、`index.html`、`app.js`、`engine.js`、`style.css`、`manifest.webmanifest`、`sw.js`、`icons`フォルダーをアップロードします。ZIP自体をアップロードするのではなく、中身を配置してください。
3. リポジトリの **Settings → Pages** で、ブランチから公開する設定を選び、**main / (root)** を指定して保存します。
4. 公開URLをAndroidのChromeで開きます。メニューから「ホーム画面に追加」または「アプリをインストール」を選びます（表示名は端末で異なります）。

すべて相対パスのため、リポジトリ名が付いたURLでも動く構成です。初回はオンラインで読み込みます。PWAキャッシュ完了後はオフライン用に必要なファイルを保持します。更新する際は `sw.js` の `CACHE` 名を変更してください。

## 操作

- **1分・3分・5分**を選び、スタート。
- **青い帽子があなた**。光る丸をタップすると、その場所へ自動移動します。下の「移動する場所」からも選べます。
- 移動中は行き先変更できません。遠い場所ほど移動が長く、見つかりやすくなります。
- タップしなければ、その場で待ちます。鬼の向き、薄い視界、心音を見て動くタイミングを決めます。
- 茂みや建物横は見つかりにくくても、鬼が近くまで来て調べると捕まります。
- 自分が捕まっても、仲間の様子を見守れます。時間切れまで1人でも残ればクリア。5人全員が捕まれば終了です。
- **♪ ON/OFF**で音を切り替えます。音はスタート操作後に有効になります。
- **一時停止**で休憩。別のアプリやタブへ移った場合も自動停止します。

## 内容と構造

- ステージ：滑り台、ブランコ、トイレ、茂み、ベンチ、4本の木、10個の移動ポイント。
- キャラクター：自分1人、COM4人、赤鬼1人。
- 鬼：ランダム巡回、向き付き視界、遮蔽判定、近距離の隠れ場所調査、発見後の接近・捕獲。
- COM：待機、移動、鬼が近いときの避難判断。
- 緊張の演出：Web Audioの心音、画面端の暗さ、微弱な揺れ、発見の「！」。端末の動きを減らす設定では揺れを省略。
- `engine.js` は画面・音から独立したゲーム状態とAI。`captured` 状態を保持し、将来の救出に拡張できます。
- `app.js` は描画、入力、音、UI。視界表示は `viewSettings.showVision` で切り替えられる構造です。
- データ収集、広告、外部へのユーザー情報送信はありません。遊具・キャラクター・アイコンは同梱の自作描画です。

## 開発検証

Node.jsで `npm test` を実行できます。追加パッケージは不要です。結果と未確認項目は `VALIDATION.md` を参照してください。
