# Hide and Seek — Phase 3.5

広い夕暮れ公園で、2体の赤鬼から隠れ、仲間を救出するスマホ向けWebゲーム。最新の「Phase 2・フィールド拡張版」を基準に更新しました。

## 起動・GitHub Pages

ローカルでは、このフォルダーで `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。HTMLのダブルクリックではモジュールとPWAが動きません。

ZIPを展開し、**中身をリポジトリ直下へ**配置してください。`index.html`、各JS、CSS、`sw.js`、manifest、`icons/`、**`audio/`** をまとめてアップロードします。GitHubの Settings → Pages で、ブランチ `main` / フォルダー `(root)` を指定して公開します。依存パッケージのインストールやビルドは不要です。すべて相対パスなので、リポジトリ名付きのURLで動作します。

Android Chromeで公開URLを開き、「ホーム画面に追加」または「アプリをインストール」。初回のキャッシュ完了後は音源を含めてオフライン起動できます。今回はキャッシュ名を `hide-seek-phase35-v1` に更新しています。旧版を開いている場合は、一度すべて閉じて開き直してください。

## 遊び方

1. 1分・3分・5分を選んでスタート。音はこの操作後に始まります。
2. 青い帽子のキャラを操作。光るポイントをタップすると自動で歩きます。
3. 画面をなぞって公園を見渡せます。全体図をタップして見る場所を変え、「操作中へ」で追従へ戻します。下の場所一覧から画面外の目的地も選べます。
4. 隠れ場所は1人用。先客がいたら「だれかいる！」と表示され、その場から別の場所へ歩いて向かいます。
5. 仲間が捕まったら、牢屋の鍵マークへ行くと全員救出。自分が捕まると、生きている仲間に自動交代します。救出後も現在の操作キャラを維持します。
6. 鬼の正面を避けましょう。「見つかりそう」の短いスロー中は、移動途中でも1回だけ行き先を選び直せます。正式に発見されると鬼が近づいて捕獲します。

時間切れに1人でも残れば成功。全員捕獲で敗北です。スロー中も制限時間は通常どおり進みます。音ON/OFF、一時停止、再スタートは従来どおり。別タブや別アプリへ切り替えると自動で一時停止します。

## 今回の変更

### 公園と鬼

世界 **560×800**、表示範囲 **420×600**、Canvas **840×1200**、16ポイント、遊具の座標、キャラの大きさ、歩行速度61を維持。対角の移動時間も拡張版と同じ19.84秒です。巡回速度47・追跡速度105も変更していません。

鬼は2体。「鬼1」「鬼2」の表示と全体図で確認できます。各鬼は向き・経路・巡回先・追跡対象・視認蓄積を個別に保持。北／南を70%の確率で優先し、30%は全域から次の巡回先を選びます。同じ目的地の選択を避けつつ、経路の交差は起こります。牢屋の前も訪れますが、各地点での滞在は有限で、専属の守備役は置いていません。同じキャラを2体が同時に追い続ける割り当ても行いません。

**基準コードには救出ルールのみがあり、ノーマル／レスキュー／サバイバルの選択UIはありませんでした。今回もそのUI構成を維持しています。** 未存在のモードを実装済みとは扱っていません。将来のサバイバル用に `lateOniAt: .27` をルールへ渡すと残り27%で3体目を追加できる仕組みを用意し、ロジック検証しています。通常の起動では追加されません。

### 視野が弱く感じた原因と修正

| 原因 | 修正 |
|---|---|
| 茂みでは正面から見えても発見まで約12秒のゲーム内時間 | 隠れ効果を残して約1.95秒に短縮。移動中は約0.51秒、広場では約0.60秒の猶予 |
| 視認距離145、視野の全角約71° | 距離175、全角約96°。真横・背後は見えない |
| 視野表示が遮蔽物の向こうまで伸びる | 同じ遮蔽物で描画を切り取り、表示と判定を一致 |
| 移動先に着くと視認蓄積をリセット | 到着・迂回ではリセットしない。見えなくなれば徐々に減る |
| 追跡中は他キャラの視認を更新しない | 追跡中も各鬼の視認蓄積を更新。現在の追跡完了後に対象を選ぶ |

角度は `atan2` と正規化した角度差、距離と遮蔽はワールド座標で判定します。カメラ座標は描画とタッチ座標変換だけに使用します。障害物による遮蔽は完全に視線を遮断し、茂みなどの隠れ効果は発見を遅らせます。表の猶予はスローがない場合の目安です。

フォーカスは危険度と向き・視野・遮蔽・発見の進行度から発動。1.35秒、速度0.6倍／発見直前0.42倍、8秒クールダウン＋危険解除後の再発動という既存設計を維持しています。

### 隠れ場所の定員

茂み・木・トイレ横・滑り台裏・ベンチ等は定員1人。ブランコ付近、広場、東の散歩道、救出ポイントは開放地点で定員制の対象外です。

出発時は満員でも目的地を選べます。約23座標単位以内に近づいて先客を確認し、150単位以内の空いた隠れ場所へ経路を作り直します。空きがなければ直前の地点へ戻り、そこも使用中なら広場へ移動します。全行程を歩き、ワープはしません。満員を理由に出発前キャンセルや予約はしません。

COMにも同じ到着判定を使い、同時到着は先に入った1人が占有します。正式発見されたがまだ捕獲されていないキャラも場所を占有します。捕獲・出発で空きになり、救出後の退避も同じ定員チェックを通ります。

### BGMとSE

| 状態 | 提供音源 | 実ファイル | 音量係数 |
|---|---|---|---|
| 通常・ループ | みどりの公園.mp3 | audio/park.mp3 | 0.36 |
| 危険・ループ | サビついたカギ.mp3 | audio/danger.mp3 | 0.43 |
| 発見・1回 | 驚く.mp3 | audio/spotted.mp3 | 0.65 |
| 捕獲・1回 | ショック1.mp3 | audio/captured.mp3 | 0.80 |

提供ファイルをそのままコピーし、ハッシュ一致を確認しています。ファイルの音量加工はせず、再生側のGainで調整しています。通常BGMは約120秒、危険BGMは約11秒でループします。

2体の**最大危険度**が0.57以上、またはフォーカス中なら危険BGMへ。危険度が0.34以下で1.8秒続いたら通常へ戻ります。切替は0.65秒のクロスフェード。鬼の接近 → 危険曲 → 心音＋スロー → 発見SE → 追跡 → 捕獲SEを連携します。発見・捕獲SEはイベントの状態遷移に対して1回だけ鳴り、BGMの上に重なります。最後の捕獲SEはリザルト移行でも最後まで再生します。

OFFはBGMとSEの音源ノードを停止し、音声コンテキストも停止。ONはユーザー操作で音を再開し、現在の危険状態に合うBGMへ戻します。一時停止／画面非表示も音を停止。再スタートは古い曲・SEを止めて通常曲から始めます。音の読み込みに失敗してもゲーム操作は続行できます。

## コードの構造と検証

- `engine.js`：ゲーム状態、複数鬼、視界、定員、捕獲・救出・操作交代。DOMと音源に依存しません。
- `camera.js`：固定した表示倍率での追従・スクロール・座標変換。
- `sound.js`：危険曲の状態遷移、MP3デコード、クロスフェード、音ON/OFF、SEの重複防止。
- `app.js`：描画・タッチ・通知・音のイベント接続。
- `rescueRules`：鬼数、救出の有無、捕獲位置、救出対象、勝敗条件。将来のモードはこのルールを差し替えます。缶蹴りや氷鬼の固有処理・UIは追加実装が必要です。

Node.jsがある環境で `npm test`。ブラウザ検証は `npm install --no-save playwright` と `npx playwright install chromium` の後、`node tests/browser.test.mjs` と `node tests/audio-browser.test.mjs` を実行します。QA専用の参照はテスト用HTTPサーバーが注入し、配布ゲーム本体には入りません。

詳しい確認結果とAndroid実機の未確認項目は `VALIDATION.md` を参照してください。アカウント・広告・解析・ユーザー情報の外部送信はありません。
